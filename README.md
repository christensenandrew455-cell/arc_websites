# ARK Client Center public site

This repository contains the public ARK Client Center website at `arkwebsites.com`.

## Public pages

- `/` product overview
- `/about` platform explanation
- `/download` Android and iOS app access options
- `/support` sales, account, privacy, and messaging support form
- `/privacy` privacy and SMS data policy
- `/terms` platform and messaging terms

## Environment variables

Copy `.env.example` and configure `ARK_SUPPORT_API_BASE_URL` so website support requests are delivered to the administrator inbox. The live-demo phone and mobile-store URLs are optional. Until an exact mobile listing URL is configured, mobile Get the App buttons open the correct store's search for “ARK Client Center.”
